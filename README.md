# Proyek HTML dan CSS Dasar

Proyek latihan pemula yang dibuat mengikuti materi dalam file pembelajaran **Pemrograman Web Dasar HTML dan CSS** yang kamu unggah.

## Isi proyek
- `index.html` — struktur halaman, judul, paragraf, daftar, dan tautan.
- `style.css` — warna, ukuran teks, jenis huruf, perataan teks, margin, padding, dan class sederhana.

## Cara membuka
1. Ekstrak file ZIP.
2. Pastikan `index.html` dan `style.css` berada dalam folder yang sama.
3. Klik dua kali `index.html` untuk membukanya di browser.

## Sebelum diunggah ke GitHub
- Ganti tautan GitHub contoh dengan alamat profil GitHub kamu.
- Ubah kalimat pada bagian “Tentang Saya” agar sesuai dengan dirimu.
- Coba ubah warna atau ukuran teks di `style.css` untuk latihan.

Ini merupakan proyek latihan dasar, bukan klaim pengalaman kerja profesional.
